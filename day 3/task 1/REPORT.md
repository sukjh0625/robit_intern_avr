# I2C, UART, RS-232, RS-485 통신 정리

## 1. I2C 개념

I2C는 두 개의 선으로 여러 장치를 연결하는 통신 방식이다. 주로 마이크로컨트롤러와 LCD, 센서, 메모리 같은 주변 장치 사이의 통신에 사용된다.

## 2. SCL

SCL(Serial Clock Line)은 클록 신호선이다. 통신 속도와 데이터를 읽는 타이밍을 맞춰 준다. 송신 장치가 SCL 신호를 만들어 통신의 박자를 정한다.

## 3. SDA

SDA(Serial Data Line)는 데이터 신호선이다. 장치 주소, 명령어, 실제 데이터 등을 전송한다. 송신 장치는 SDA 선을 통해 0과 1의 데이터를 보낸다.

## 4. SCL과 SDA의 특징

SCL과 SDA는 평소에 모두 HIGH 상태이다. 장치가 신호선을 직접 HIGH로 출력하는 방식이 아니라, 필요할 때만 LOW로 내리는 방식으로 동작한다. 따라서 선을 평소 HIGH 상태로 유지하기 위한 풀업 저항이 필요하다. 대부분의 I2C LCD 모듈에는 풀업 저항이 이미 연결되어 있으므로 별도로 연결하지 않아도 되는 경우가 많다.

## 5. TWI

TWI(Two Wire Interface)는 ATmega에서 I2C 통신을 처리하는 전용 하드웨어이다. 대표 레지스터는 다음과 같다.

| 레지스터 | 기능 |
| --- | --- |
| `TWBR` | 통신 속도 설정 |
| `TWSR` | 통신 상태 확인 |
| `TWDR` | 송수신 데이터 저장 |
| `TWCR` | START, STOP, 전송 시작 등의 동작 제어 |

## 6. I2C 통신 원리

통신을 시작할 때 SCL이 HIGH인 상태에서 SDA를 HIGH에서 LOW로 바꾼다. 이를 START 조건이라고 한다. 이후 SCL이 LOW일 때 SDA에 0 또는 1을 설정하고, SCL이 HIGH가 되는 순간 수신 장치가 SDA 값을 읽는다. 데이터는 한 번에 8비트씩 전송한다. 8비트 전송 후 9번째 클록에서 수신 장치는 SDA를 LOW로 만들어 ACK 신호를 보낸다. ACK는 데이터를 정상적으로 받았다는 뜻이다. 마지막으로 SCL이 HIGH인 상태에서 SDA를 LOW에서 HIGH로 바꾸면 STOP 조건이 되며 통신이 종료된다.

```text
START → 주소 또는 데이터 8비트 → ACK → 주소 또는 데이터 8비트 → ACK → STOP
```

## 7. UART 기본 개념

UART는 데이터를 비동기 직렬 방식으로 보내고 받는 통신 방식이다. 시작 비트, 데이터 비트, 정지 비트를 사용하여 데이터를 전송한다. RS-232와 RS-485는 UART 데이터를 실제 선으로 전달하기 위한 전기적 통신 규격이다.

## 8. RS-232와 RS-485의 차이

| 구분 | RS-232 | RS-485 |
| --- | --- | --- |
| 신호 방식 | 한 선의 전압을 기준으로 판단 | 두 선의 전압 차를 이용 |
| 통신 형태 | 1대1 통신 | 여러 장치 연결 가능 |
| 통신 거리 | 짧음 | 김 |
| 노이즈 영향 | 비교적 큼 | 비교적 작음 |
| 통신 방향 | 송신과 수신 동시 가능 | 보통 반이중 통신 |

RS-232는 가까운 거리에서 장치 하나를 간단히 연결할 때 편리하다. TX와 RX 선이 분리되어 있어 송신과 수신을 동시에 할 수 있지만, 한 선의 전압을 기준으로 신호를 판단하므로 노이즈와 긴 배선에는 비교적 약하다.

RS-485는 두 선의 전압 차이를 이용하므로 노이즈에 강하고 먼 거리 통신에 유리하다. 또한 여러 장치를 하나의 통신선에 연결할 수 있어 공장 자동화, 모터 제어, 센서 네트워크 등에 많이 사용된다. 다만 보통 하나의 선을 송신과 수신이 함께 사용하므로, 한 순간에는 한 장치만 데이터를 보내야 한다.

## 9. 정리

I2C는 SCL과 SDA 두 선을 이용해 여러 장치와 통신하는 방식이다. UART는 비동기 직렬 데이터 전송 방식이며, RS-232와 RS-485는 UART 신호를 실제 선으로 전달하는 전기적 규격이다. 가까운 거리의 간단한 1대1 연결에는 RS-232가 편리하고, 먼 거리·노이즈 환경·여러 장치 연결에는 RS-485가 유리하다.
