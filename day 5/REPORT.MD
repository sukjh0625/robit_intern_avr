# 레지스터 설정에 관한 보고서

## 1. 레지스터의 정의

레지스터란 마이크로 컨트롤러 내부에 있는 작은 고속 저장공간이다. 이트메가에서는 값을 저장하여 핀의 입출력 타이머 UART 타이머같은 기능을 설정하고 현재 상태를 확인한다.

## 2. 레지스터 설정

레지스터 설정이란 각 비트에 0이나 1을 넣어서 아트메가의 하드웨어 동작 방식을 정하는 것이다 예를들어 
'DDRA = 0xFF;' 모든비트를 1로 설정하고 PAX핀을 모두 출력에 사용한다

## 3. PWM +TIMER1과 관련된 레지스터

### TCCR1A 
PWM의 출력 방식과 파형 모드를 설정해준다. 비트에는 COMA1등이있고 OC1X핀의 출력방식을 설정한다
일반적으로 PWM 설정 'TCCR1A = (1 << COM1A1) | (1 << WGM11);' 이렇게 한다


### TCCR1B 
파형모드 분주비 입력 캡쳐를 설정한다. 6비트의 ICES1는 0에서 하강 엣지에서 1은 상승엣지에서 입력캡쳐한다.

### TIMSK
TIMER 1인터럽트 사용여부 설정한다. 특히 2번비트의 TOIE1비트만 1로 만들어서 오버플로 인터럽트를 킨다.
예시로는 TIMSK |= (1 << TOIE1);이런식으로 사용한다

### 그외 레지스터
TCCR1C | 강제로 비교 일치를 발생시킴 |
TCNT1 | TIMER1이 현재 세고 있는 숫자 |
OCR1x | TCNT1 과 비교할 값 PWM의 듀비티 결정. 듀비티란 한주기동안 신호가 켜져 있는 시간을 의미한다 |
ICR1 | 입력 캡처 값 저장 PMW의 TOP 값 결정 |
TIMSK | TIMER 1인터럽트 사용여부 설정 |
ETIMSK | 추가 출력 비교 인터럽트 설정 |
TIFR| TIMER1 인터럽트 발생 상태 확인
ETIFR| 추가 인터럽트 발생 상태 확인
SREG | 전체인터럽트 활성화
SFIOR | TIMER 관련 특수 기능 설정
