# TIMER0, TIMER2 원리 및 사용 방법

## 1. 타이머 기본 원리

TIMER0와 TIMER2는 모두 8비트 타이머이다. 따라서 타이머 카운터는 `0`부터 `255`까지 셀 수 있으며, `255` 다음에는 다시 `0`으로 돌아간다. 이때 `255`에서 `0`으로 돌아가는 현상을 오버플로(Overflow)라고 한다.

ATmega가 16 MHz로 동작한다면 CPU는 1초에 16,000,000번 동작한다. 이 속도를 그대로 타이머에 사용하면 너무 빠르므로 분주비를 사용해 타이머의 증가 속도를 낮춘다.

예를 들어 분주비를 64로 설정하면 타이머는 다음 속도로 증가한다.

```text
16,000,000 Hz / 64 = 250,000 Hz
```

따라서 타이머 값은 1초에 250,000번 증가한다. 타이머가 한 번 증가하는 시간은 다음과 같다.

```text
1 / 250,000 = 4 us
```

8비트 타이머는 0부터 255까지 총 256번 증가한 뒤 오버플로가 발생한다. 따라서 오버플로 발생 주기는 다음과 같다.

```text
256 × 4 us = 1024 us
```

즉, 16 MHz에서 분주비를 64로 설정하면 TIMER0 또는 TIMER2는 약 1.024 ms마다 한 번 오버플로가 발생한다.

## 2. 주요 레지스터

| 레지스터 | 기능 |
| --- | --- |
| `TCNT0`, `TCNT2` | 현재 타이머의 숫자를 저장하는 카운터 레지스터 |
| `TCCR0`, `TCCR2` | 타이머 동작 방식과 분주비를 설정하는 제어 레지스터 |
| `TIMSK` | 사용할 타이머 인터럽트를 허용하는 레지스터 |
| `OCR0`, `OCR2` | 비교 일치 모드에서 사용할 목표 숫자를 저장하는 레지스터 |

`TCNT0`과 `TCNT2`에 값을 직접 넣으면 타이머가 그 값부터 시작한다. 예를 들어 `TCNT0 = 6;`으로 설정하면 6부터 255까지 세므로, 오버플로까지 250번만 세게 된다.

## 3. 오버플로 방식

오버플로 방식은 타이머가 255까지 센 뒤 0으로 돌아가는 순간 인터럽트를 발생시키는 방식이다. 일정 시간을 반복해서 세거나 시간 측정, LED 깜빡임 등에 사용할 수 있다.

```text
0 → 1 → 2 → ... → 255 → 0
                         ↑
                    Overflow Interrupt
```

## 4. 비교 일치 방식

비교 일치 방식은 타이머가 255까지 모두 셀 필요 없이, 타이머 값이 목표 값과 같아졌을 때 인터럽트를 발생시키는 방법이다. 목표 값은 `OCR0` 또는 `OCR2`에 저장한다.

예를 들어 `OCR0 = 124;`로 설정하면 타이머 값이 124가 되는 순간 비교 일치 인터럽트가 발생한다. 따라서 원하는 시간에 더 가깝게 인터럽트를 만들 수 있다.

## 5. 분주비 사용 예시

4일차의 년·월·일 과제에서는 시간 측정을 위해 분주비를 사용하였다. 또한 3일차 4번 과제에서도 타이머 속도를 조절하기 위해 분주비를 사용하였다. 분주비는 타이머가 너무 빠르게 증가하지 않도록 하여 사람이 확인할 수 있는 시간 단위로 동작하게 만든다.

## 6. `sei()`

`sei()`는 전체 인터럽트를 허용하는 코드이다. 타이머 인터럽트를 레지스터에서 켜더라도 `sei()`를 실행하지 않으면 인터럽트 서비스 함수가 실행되지 않는다. 따라서 타이머 인터럽트를 사용할 때는 초기 설정이 끝난 뒤 `sei()`를 호출해야 한다.
